개인정보처리방침 · Privacy Policy

시행일 · Effective date: 2026-11-10

"볼파이트 업로드 도구"(이하 "도구")는 유튜브 채널 볼파이트 오브 캐릭터즈와 쿠키런 볼파이트의 운영자가 자기 채널을 관리하기 위해 본인 컴퓨터에서만 쓰는 개인용 프로그램이에요. 운영자 외의 사용자는 없어요.

"Ballfight Upload Tool" (the "Tool") is a private program the owner of the YouTube channels Ballfight of Characters and Cookie Run Ballfight runs only on their own computer to manage their own channels. It has no users other than the owner.

1. 접근하는 정보 · Data the Tool accesses

운영자가 Google 계정으로 로그인해 허용한 범위에서, 운영자 본인의 유튜브 계정에 대해서만 YouTube API 서비스를 통해 다음에 접근해요.

With the owner's consent through Google sign-in, and only for the owner's own YouTube account, the Tool uses YouTube API Services to access:

  • 채널 기본 정보(채널 이름, 업로드 목록) · basic channel information (channel name, list of uploads) — youtube.readonly
  • 영상 업로드 · uploading videos — youtube.upload
  • 재생목록에 영상 추가, 댓글 작성 · adding videos to playlists, posting comments — youtube.force-ssl
  • 채널·영상 통계(조회수, 시청 시간, 시청 지속률 등) · channel and video analytics (views, watch time, retention) — yt-analytics.readonly

다른 사람의 계정이나 시청자의 개인정보는 수집하지 않아요. · The Tool does not collect data about any other account or about viewers.

2. 이용 목적 · How the data is used

운영자가 요청할 때 운영자 채널에 영상을 올리고, 운영자 채널의 통계를 운영자에게 보여주는 데에만 써요. 광고, 분석 판매, 머신러닝 학습 등 다른 목적으로 쓰지 않아요.

Only to upload the owner's videos to the owner's channels when the owner asks, and to show the owner their own channel analytics. It is never used for advertising, sold, or used for any other purpose, including training machine-learning models.

3. 저장 · Storage

로그인 토큰(갱신 토큰)은 운영자 컴퓨터의 로컬 파일에만 저장돼요. 통계 결과는 운영자 컴퓨터의 화면이나 메모에만 남고, 외부 서버에 저장하지 않아요.

The sign-in (refresh) token is stored only in a local file on the owner's computer. Analytics results stay on the owner's computer; nothing is stored on any external server.

4. 제3자 제공 · Sharing

어떤 정보도 제3자에게 제공·판매·전송하지 않아요. 요청은 운영자 컴퓨터에서 Google(YouTube) 서버로만 직접 가요.

No data is shared with, sold or transferred to any third party. Requests go directly from the owner's computer to Google (YouTube) servers.

5. Google API 정책 준수 · Google API Services User Data Policy

도구가 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.

The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

도구는 YouTube API 서비스를 사용해요. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용돼요.

The Tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

6. 권한 철회와 삭제 · Revoking access and deletion

언제든 Google 계정 보안 설정 → 서드 파티 액세스에서 이 도구의 권한을 철회할 수 있어요. 철회하거나 운영자 컴퓨터의 토큰 파일을 지우면 도구는 더 이상 계정에 접근할 수 없어요.

Access can be revoked at any time at Google Account → Third-party access. Once revoked, or once the local token file is deleted, the Tool can no longer access the account.
